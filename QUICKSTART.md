# Quick Start Guide - Al Rasid Trading Co

## ⚡ Get Started in 30 Seconds

### Step 1: Open the Website
1. Navigate to: `c:\Users\DELL\web test\al-rasid-trading\`
2. Double-click `index.html`
3. Your default web browser opens with the full e-commerce site

**Done!** The website is ready to use.

---

## 🛍️ Customer Walkthrough

### 1. Browse Products
- See all featured products on the home page
- Use categories (Electronics, Computers, Photography, Home & Office)
- Use the search bar to find specific items

### 2. View Product Details
- Click any product to see full details
- Check price, rating, reviews, and description
- See stock availability

### 3. Add to Cart
- Click "Add to Cart" or the eye icon to view details
- Quantity automatically updates in cart icon (top right)

### 4. Checkout
1. Click the cart icon (top right)
2. Review items and quantities
3. Click "Proceed to Checkout"
4. Fill in:
   - Full Name
   - Email
   - Phone Number
   - Delivery Address
5. Click "Complete Order"
6. Success! Order confirmation displayed

---

## 👨‍💼 Admin Walkthrough

### Access Admin Panel
1. Click the "Admin" button (top right, with gear icon)
2. Admin menu slides in from left side

### Add New Product
1. Click "Manage Products"
2. Form appears with fields:
   - **Product Name**: Enter product name
   - **Price**: Enter price in dollars
   - **Category**: Choose or create category
   - **Emoji**: Add an emoji as product image (e.g., 📱, 🎧, 💻)
   - **Stock**: Number of units available
   - **Description**: Brief product description

3. Click "Add Product"
4. Product appears in store immediately

### View Dashboard
- Click "Dashboard" to see statistics
- Total orders, pending orders, inventory count

### View Orders
- Click "Orders" to see all customer orders
- Shows customer details and delivery addresses
