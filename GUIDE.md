## ❓ Frequently Asked Questions

### Q: Do I need to code?
**A:** No! Everything is in one HTML file. Just open it.

### Q: How do I change the company name?
**A:** Edit [CUSTOMIZATION.md](CUSTOMIZATION.md) Section 1. Takes 2 minutes.

### Q: Can I deploy this online?
**A:** Yes! See [DEPLOYMENT.md](DEPLOYMENT.md). Takes 5 minutes.

### Q: Will customers' orders be saved?
**A:** Not yet. They refresh and disappear. Add Firebase to fix (see [BACKEND_SETUP.md](BACKEND_SETUP.md))

### Q: Do I need a domain name?
**A:** You get a free `.netlify.app` domain. Optional: Buy custom domain ($10-15/year)

### Q: Can I add payment processing?
**A:** Yes, later. First get the basic store working, then integrate Stripe.

### Q: Is this secure for real customers?
**A:** For testing, yes. For real money, see [BACKEND_SETUP.md](BACKEND_SETUP.md) for security improvements.

### Q: Can I sell on multiple platforms?
**A:** Yes. This is just one store. You can create multiple copies.

### Q: What if I break something?
**A:** You can revert changes or download the original file again.

## 🐛 Troubleshooting

### Website won't open
- [ ] Is `index.html` in the right folder?
- [ ] Try a different browser (Chrome, Firefox, Edge)
- [ ] Clear browser cache (Ctrl + Shift + Delete)

### Colors/Text didn't change
- [ ] Did you save the file? (Ctrl + S)
- [ ] Did you refresh the browser? (F5)
- [ ] Clear browser cache

### Products disappeared
- [ ] Refresh the page (F5)
- [ ] This is normal - data resets without a backend

### Admin button doesn't work
- [ ] Click exactly on the word "Admin"
- [ ] Check browser console (F12 → Console)
- [ ] Try a different browser

### Checkout not working
- [ ] Make sure you added products first
- [ ] Check all fields are filled
- [ ] See browser console for errors (F12)
